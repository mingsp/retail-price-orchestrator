# 新人演练与独立操作验收

## 1. 为什么必须验收

读完文档不等于能安全接手。新人必须先在脱敏样例和非生产环境中证明自己能够识别资源、
判断风险、保留断点和恢复任务，再获得真实采集权限。

## 2. 能力等级

| 等级 | 能力 | 允许动作 |
|---|---|---|
| L0 | 阅读入口和边界 | 不执行命令 |
| L1 | 运行离线校验和样例回放 | 只读本地包 |
| L2 | 在测试配置中识别 Worker/Slot/账号/Profile/门店 | 不连接生产账号 |
| L3 | 在监督下完成登录、风险分类和小类目 Canary | 单 Slot、单门店 |
| L4 | 独立执行批次、换号恢复、质量验收和交付 | 按授权范围生产操作 |

交接包只能证明 L0～L2 可用；L3～L4 必须由现场负责人签字确认。

## 3. 必做桌面演练

### 场景 A：目标门店 403，普通店正常

合格答案：

- 停止目标门店请求。
- 记录 `target_poi_block` 或 `instant_retail_block` 的分类证据。
- 账号冷却，Profile 进入风险观察。
- 不刷新、不换参数、不从深页重试。
- 从健康账号和新纯采集 Profile 迁移缺口任务。

### 场景 B：新账号准备登录旧 Profile

合格答案：

- 立即阻断。
- 新建 Profile 和唯一绑定。
- 不复制 Cookie、localStorage、UUID 或旧参数。
- 人工登录后做首屏预检和小类目 Canary。

### 场景 C：同设备两个账号同时出现超市 403

合格答案：

- 停止该 Worker 新任务和新账号登录。
- 标记 `device_or_ip_risk`。
- 核对网络、定位、系统时间和其他设备对照结果。
- 不继续增加账号试错。

### 场景 D：验证码已由人工完成

合格答案：

- 低频确认页面已恢复。
- 重新核对账号、门店 ID 和商品可见性。
- 先做不发商品请求的预检，再从 checkpoint Canary 恢复。

### 场景 E：换号后已有 80% 原始数据

合格答案：

- 不从零重采。
- 冻结旧 lease，校验 raw 和 checkpoint。
- 只迁移计划、完成类目和已落盘商品 ID。
- 新账号只补有效缺口，并按商品 ID 去重。

### 场景 F：页面显示完成但 raw 类目标记缺失

合格答案：

- 不宣布完成。
- 对账 checkpoint、raw、类目标记、嵌套 SKU 和展示价质量。
- 缺少证据的类目回到待补或人工复核。

## 4. L3 现场 Canary 清单

- [ ] 正确定位唯一 Worker 和 Browser Slot。
- [ ] 确认账号、Profile、CDP 和门店绑定一致。
- [ ] Profile 为纯采集且没有商家后台痕迹。
- [ ] 人工登录过程未保存密码、短信码或 Cookie。
- [ ] 首屏门店 ID 和标题正确。
- [ ] 小类目采集只产生批准范围内的请求。
- [ ] raw JSONL、progress 和 checkpoint 正常追加。
- [ ] 暂停后可从 checkpoint 续采。
- [ ] 模拟风险事件可阻断任务并生成通知。
- [ ] 商品名称、嵌套 SKU 和展示价字段通过检查。

## 5. L4 独立操作验收

- [ ] 能制定门店类目分工且无账号重叠。
- [ ] 能解释门店唯一 SPU/SKU 与类目关系数的区别。
- [ ] 能独立分类 403，而不是直接判断“封号”。
- [ ] 能执行账号冷却、Profile 隔离和换号迁移。
- [ ] 能识别设备/IP 聚集风险并停止扩大影响。
- [ ] 能处理验证码、登录失效和授权码过期。
- [ ] 能完成 50%/100% 里程碑和风险通知。
- [ ] 能验证 artifact 哈希、原始数据完整性和重复执行幂等性。
- [ ] 能说明哪些结论是当前现场证明、哪些只是历史经验。
- [ ] 能在不删除历史证据的情况下完成批次归档。

## 6. 验收记录

记录以下内容：

- 接手人和验收人。
- 交接包版本与 SHA-256。
- 离线校验结果。
- 演练场景结果。
- Canary 门店、Slot 和任务的脱敏标识。
- 发现的问题与修复证据。
- 获得的最高能力等级。
- 验收时间和下次复审时间。

未达到 L3 的人员不得独立登录生产账号；未达到 L4 的人员不得独立更换账号/Profile 或宣布
门店批次完成。
